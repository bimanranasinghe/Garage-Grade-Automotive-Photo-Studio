# Garage Grade — Automotive Photo Studio

**Owner:** BIMAN RANASINGEH

Garage Grade is a browser-based automotive photo editing and enhancement studio designed for creating polished, cinematic car photography directly in the browser.

## ✨ Features

- 📸 Automotive photo editing
- 🎨 Photo enhancement and cinematic color grading
- 🔍 Progressive image upscaling with a 4K export option
- ✍️ Custom text editing
- 💧 Watermark support
- 🖼️ Logo upload with position, size, and opacity controls
- 📐 Export at original resolution or upscale to 4K
- 🧹 Metadata remover for cleaning image metadata
- 📝 Custom metadata support
- 📦 Batch metadata processing with ZIP export
- 🏷️ Custom output file names
- 🔄 Reset all edits
- 📱 Responsive interface for different screen sizes

## 🛠️ Metadata Tools

The Metadata Remover section can:

- Remove existing image metadata
- Create a fresh exported image without the original metadata
- Add selected custom metadata back to the exported image
- Set camera make and model
- Set artist / photographer
- Set copyright
- Set date and time taken
- Set software information
- Add a custom description
- Process multiple photos and export them as a ZIP file

When custom metadata is used, the original camera/GPS metadata is removed first and only the values entered by the user are added back.

## 🚗 Export

Garage Grade supports:

- Original/native-resolution export
- 4K upscale export
- Custom export file names
- Clean image export after metadata processing

## 💻 How to Use

1. Open the HTML file in a modern web browser.
2. Upload a photo.
3. Apply the available editing and enhancement tools.
4. Add text, watermark, or a logo if needed.
5. Choose the desired export size.
6. Enter a custom file name if required.
7. Export the finished image.

For metadata cleaning:

1. Open the **Metadata Remover** tab.
2. Upload one or more images.
3. Choose **Remove all metadata** or **Set custom metadata**.
4. Enter custom metadata if required.
5. Process and download the resulting ZIP file.
